# `konspekt` — Partition `output`

> PDF composition: notes + quiz + figures rendered through Typst into
> the final study-notes document.

---

## 1. Context

The output partition owns pipeline stage 8, `compose`. It renders the
notes artifact (analysis:CON-022) and the quiz artifact
(analysis:CON-023) into Typst markup and compiles it to
`<out>/<lecture-slug>/konspekt.pdf` with the `typst` Python package
(bundled compiler, no system Typst installation). Lectures are Russian
or English, so the document font MUST cover Cyrillic and Latin.

## 2. Glossary

- **Typst markup** — the intermediate `.typ` source generated by the
  compose stage, kept in the work directory for debugging.
- **Answer key** — the final document section listing the correct
  option / model answer for every quiz question.
- **Tofu glyph** — the replacement box a font renders for a missing
  code point.
